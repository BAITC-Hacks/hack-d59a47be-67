# Локальные данные

Исходный `career_quest_dataset.zip` и каталог `data/raw/` не входят в Git. ТЗ
ограничивает распространение стартового кита рамками хакатона. Исходники никогда
не исправляются скриптами: сомнительные значения фиксируются в аудите.

Из корня проекта, Python 3.10+ (сторонние пакеты не нужны):

```bash
python3 scripts/prepare_dataset.py career_quest_dataset.zip
python3 scripts/audit_dataset.py data/raw
```

Если кит уже распакован, передайте папку, непосредственно содержащую семь файлов:

```bash
python3 scripts/prepare_dataset.py /absolute/path/to/career_quest_dataset
```

Подготавливаются только `employees.json`, `events.json`, `skills.json`,
`activity_history.csv`, `README.md`, `README.ru.md`, `README.kz.md`. Метаданные
macOS и любые посторонние файлы из ZIP не извлекаются. Архив с опасным путём,
символической ссылкой, повторным именем записи или несколькими полными китами
отклоняется. Размер ограничен 20 MiB на файл и 50 MiB на кит. Существующий файл
с иным содержимым не перезаписывается; повторный запуск с тем же китом безопасен.
Назначение и его родительские каталоги не должны быть символическими ссылками;
при системных alias вроде `/tmp` используйте канонический путь.

Скрипт подготовки печатает SHA-256 каждого файла. Аудит печатает только агрегаты,
схемы, идентификаторы каталога и контрольные суммы; профили и строки истории не
выводятся. Код возврата аудита: `0` — проверки целостности прошли, `1` — найдены
нарушения, `2` — вход не читается или имеет неподдерживаемую структуру. Пройденные
проверки не отменяют смысловые неоднозначности, описанные в отчёте.

```bash
python3 scripts/audit_dataset.py data/raw > /tmp/career-quest-audit.json
python3 -m unittest discover -s tests -p 'test_dataset_tools.py' -v
```

Результаты и ограничения: [аудит](../docs/data-audit.md). Сохранённая дата снимка
`2026-10-01` служит воспроизводимыми «сегодня» для этого кита; системную дату не
нужно подставлять вместо неё. Скрипты — инструменты подготовки архитектуры, а
не готовый сервер загрузки файлов жюри. Будущий импорт дополнительных профилей
и CSV обязан поддерживать частичную загрузку без повторной поставки README и
каталогов, проверять ссылки на уже загруженный каталог и быть транзакционным.
