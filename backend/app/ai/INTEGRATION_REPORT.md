## Найдено для владельцев backend и frontend

**P2 — текст объяснения остаётся техническим JSON на английском.** Открыть «Следующий шаг» → «Почему вам подходит». Вместо краткого пользовательского основания показаны `Resolved career goal`, внутренние skill IDs, `scope`, `date_sources`, `status_counts` и длинные служебные оговорки. Это достоверные facts, но недостаточно понятное объяснение для демонстрации.

Источник: [backend service.py:554 в проверенной версии](https://github.com/BAITC-Hacks/hack-d59a47be-67/blob/33f3ef02fa89e2e0ddeffec3186e73ae1572f6e9/backend/app/service.py#L554) соединяет исходные facts и заменяет внешний explanation.text; [EmployeeWorkspace.tsx:326](https://github.com/BAITC-Hacks/hack-d59a47be-67/blob/5b85eb3/frontend/src/features/employee/EmployeeWorkspace.tsx#L326) отображает его напрямую. Простая смена текста внутри AI не исправит HTTP-ответ. Алихану: сформировать понятный текст из проверенных фактов с сохранением evidence_ids и проверок; Батыру: согласовать отображение оснований. Не извлекать машинные поля парсингом свободного текста на frontend.

**P2 — раскрытое объяснение ломает ширину мобильной страницы.** На 390×844 после раскрытия первого «Почему вам подходит» `document.documentElement.scrollWidth` становится **841** при `innerWidth=390`; часть текста уходит за экран. При закрытых основаниях и на странице истории ширина остаётся 390. На desktop 1440 overflow не воспроизведён.

Батыру: настроить перенос длинных токенов для `.why-details p` и проверить ограничения ширины карточки. Воспроизведение и результат: [скриншот](verification/recommendation-evidence-mobile.png), [styles.css:1088](https://github.com/BAITC-Hacks/hack-d59a47be-67/blob/5b85eb3/frontend/src/styles.css#L1088). После исправления проверить раскрытые основания на 390 px с настоящим ответом PR #4.

AI-ветка остаётся независимой от ещё не принятого PR #4. Файл `oleg_backend_handoff_acceptance.py` запускается явно после совмещения веток и не входит в обычный unit-прогон старого backend. Evaluator останавливается с `backend_context_not_enriched` до загрузки ключа/сети, если backend ещё не выдаёт event/cohort facts. Это не skip качества модели и не успешная оценка.

В копии с обоими PR и установленными backend-зависимостями:

```sh
python -m pytest backend/tests/oleg_backend_handoff_acceptance.py -q
python -m backend.app.ai.backend_evaluation
python -m backend.app.ai.backend_evaluation --live --env-file /absolute/path/to/local/.env
```

Первая команда проверяет семантику fixtures и обе evidence-ссылки; вторая не использует сеть. Последняя явно разрешает три реальных запроса только для фиксированных синтетических источников. Путь выбирается локально; секреты не копируются в worktree.
