# Проверки Frontend / UX

Проверено локально 2026-09-23 на Windows, Node.js 24.19.0, Python 3.12.14. Основа — backend из `codex/architecture-foundation` (`e3dfc7e`). Использованы собственные вымышленные данные; исходный кит и реальные профили не публиковались.

## Автоматические проверки

- `pnpm test`: 52 теста в 6 файлах. API-клиент (11), синтетические состояния (7), маршруты/сессии приложения (8), сценарии сотрудника (13), чтение файлов и импорт (13).
- Проверяются CSRF/cookie, отсутствие автоматического перехода в демо, ограничения роли, запоздалые ответы при смене пользователя, устаревшие рекомендации после мутации, сохранение версии/тела/idempotency key при повторе завершения после сетевой ошибки и перезагрузки, импорт с preview token, двойные клики, конфликт и потеря ответа.
- `pnpm build`: TypeScript и production bundle успешно собраны.
- `pnpm format:check`: PASS. `pnpm generate:api` не меняет SHA-256 уже сгенерированного `src/api/schema.ts`.
- `.venv/Scripts/python.exe frontend/scripts/test-live.py`: 6 групп проверок настоящего HTTP API на временной SQLite-базе. Вход/сессия/CSRF/права; профиль/каталог/честный `not_configured`; preview/завершение/replay/409; stale latest; успешный и ошибочный импорт; повторный запуск backend с сохранением профиля, сессии, импорта и идемпотентности.
- Ruff check и format для двух Python-скриптов: PASS. Runner проверен на отдельных портах `8001/5174`: backend readiness, UI и proxy 200, отказ на занятых портах до seed, остановка собственных процессов при Ctrl+C и сбое backend. Существующий сервер не затронут.

## Проверка интерфейса в браузере

- Демо: вход без пароля, подбор трёх подготовленных рекомендаций, объяснения, предварительный результат, подтверждение завершения. Прогресс 72,7% → 86,4%; предыдущая подборка помечается устаревшей; состояние сохраняется после перезагрузки. Сброс возвращает начальный профиль.
- Настоящий API с отдельными синтетическими учётками: вход сотрудника, профиль/каталог, сообщение об отключённом AI, preview и завершение курса. Серверный прогресс 56,3% → 62,5%; обновлённая история сохраняется после перезагрузки.
- HR: вход, серверная сводка, список сотрудников. Некорректный JSON показывает файл и путь ошибочного поля. Корректные JSON+CSV проходят preview с одним новым профилем и одной записью истории; после подтверждения сотрудник появляется в списке, счётчик растёт с 3 до 4.
- Адаптивность: кабинет сотрудника, HR и импорт на ширине 390 px, кабинет и навыки на 320 px; проверены мобильное меню и диалог цели. Устранено переполнение страницы таблицей HR; закрытая панель навигации скрыта от клавиатуры. Диалоги используют нативный `dialog`, есть подписи полей и переход к основному содержимому.

Проверка браузером выполнена вручную через автоматизированные действия и осмотр экранов, а не отдельным воспроизводимым e2e-suite. Полный аудит WCAG, проверка всех браузеров/устройств и нагрузочные измерения не проводились.
